IAM Lens privacy policy

Last updated: 21 November 2026

IAM Lens has no analytics, no tracking and no remote code. Everything it stores stays in your browser, and signing out deletes your custom-role data.

What IAM Lens is

IAM Lens is a browser extension that looks up Google Cloud IAM roles and permissions. It is developed by <DEVELOPER_NAME> and is not affiliated with or endorsed by Google.

No analytics, no tracking, no remote code

The extension does not collect analytics or telemetry, does not use advertising or tracking identifiers, and does not send your searches anywhere. All code that runs is shipped inside the extension package. It never downloads or runs code from a remote server.

Predefined roles snapshot

The list of Google Cloud predefined roles and permissions is bundled with the extension and refreshed periodically by downloading a public data file (the snapshot) from GitHub Pages. This is a plain request for a public file. It contains no information about you beyond what any web request normally exposes to the host, such as your IP address, which GitHub handles under its own privacy statement.

Optional sign-in and custom roles

Signing in with Google is optional and is only needed if you want to see your own organisation or project custom roles. If you sign in:

  • The OAuth access token is used only to call the Google IAM API and the Cloud Resource Manager API directly from your browser, to list the projects you can access and their custom roles.
  • The token and the data returned are never sent to the developer or to any third party.
  • Custom-role data is stored only locally in your browser (extension storage). It is not synced or uploaded.
  • Signing out revokes the token and deletes the locally stored custom-role data. You can also remove the extension to delete all of its data.

Google API Services User Data Policy

IAM Lens's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Specifically, data received from Google APIs is used only to provide and improve the user-facing lookup features, is not transferred to others, is not used for advertising, and is not read by humans.

Permissions

The extension requests only the browser permissions it needs: side panel, local storage, scheduled alarms (for snapshot refresh), and context menu. The identity permission and access to googleapis.com are optional and are requested only when you choose to sign in.

Children

IAM Lens is a developer tool and is not directed at children.

Changes to this policy
