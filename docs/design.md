# IAM Lens: Design Direction

## Concept: "Console"

IAM Lens looks like it lives inside the Cloud Console: flat surfaces, three tonal layers, small dense type, quiet blue-grey colour, outlined buttons with an accent label. Every value comes from `docs/console-reference.md` (measured light and dark). Values the reference does not cover are marked **(derived)** below. Brand-safe rules stay: the product is **IAM Lens** with its own icon, and no Google or Google Cloud logo or wordmark is reproduced. Service icons (ServiceIcon) stay colourful; every UI icon is monochrome.

Two signature elements make it ours and survive the restyle:

1. **Permission anatomy.** Every IAM permission is `service.resource.verb`. We show that structure everywhere and colour the verb by privilege.
2. **Privilege bar.** A segmented read / write / admin share bar on every role row and header, with counts.

Both live in `src/core/privilege.ts` (classifier, unit-tested) and `src/ui/components/{PermissionToken,PermissionAnatomy,PrivilegeBar}`.

### Risk hues (read / write / admin) (derived)

Kept from before as the product's meaning layer, retuned to sit in the console palette (cooler greens, burnt amber, brick red). Text roles are AA (>= 4.5:1) on panel, shell and table header; bar fills are >= 3:1 against panel and table header (non-text, WCAG 1.4.11). `gen-theme.ts` fails the run if any pair regresses.

## Typography

- Family: Google Sans Flex (self-hosted, OFL), fallback Figtree. Mono (permission and role IDs only, our signature): Google Sans Code, fallback JetBrains Mono. The console itself shows IDs in sans; mono is a deliberate IAM Lens exception.
- Measured scale: body 14/20 400; page title 18/24 500; section title 18/24 400; section heading 22/28 400; tabs, table headers, buttons, labels 14/20 500; chip 12/20 500. No letter-spacing, no uppercase except the short anatomy brackets under a permission.
- Links: link colour, underlined.

## Density, radii, elevation

- Rows: 29px minimum (4px 16px cells in the console; list rows here use 6px 16px because they carry two lines). Buttons and icon buttons 32px (icon buttons 24px when `sm`), tabs 36px.
- Radii: button and nav pill 12px, banner/error 16px, panel 20px (top corners), chip and tooltip 4px, round icon buttons, privilege bar segments 2px.
- Elevation: none. All `--md-sys-elevation-*` tokens are `none`; hierarchy is tone only. Dialogs use a hairline border over a 50% scrim.

## Motion

Short and quiet: 100 to 200ms standard easing, no springs, no stagger, no shape morphing. Route changes keep a shared-axis X transition but with 16px travel and 100/200ms timing. `prefers-reduced-motion` falls back to opacity only.

## Removed from the previous direction

Dot grid (the `.dot-grid` class is gone from the stylesheet; leftover class names in screens are inert), M3 Expressive pills, state-layer shape morphs, spring easing, elevation shadows, display-size tracking, uppercase eyebrow labels, the search bar morph.

## Layout

Unchanged in this ticket (IAM-36 restyles the side panel, popup and options layouts to console patterns: shell + panel with 20px top radius, breadcrumb, table-style lists, banners).

## Accessibility guardrails

Contrast is AA in both themes (checked at generation time and by axe in `e2e/a11y.spec.ts`), focus rings are visible (2px accent), everything works from the keyboard, and `/` focuses search.
